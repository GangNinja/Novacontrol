Perception

Vision

The vision model looks at your screen, guides clicks to the right option inside apps, and verifies what it did. Failures are logged to the bug file (what, where, when) so you can review and fix them later.

Describe Screen

Capture the screen and report what is visible — apps, windows, notable text.

Guided Click

Name a button or menu (e.g. "File", "Library", "Play GTA V") — the vision layer finds it on screen, clicks it, and verifies.

Vision Model

Optional: wire a multimodal model so element location is semantic instead of OCR-only. Ollama (local) needs a vision model pulled, e.g. ollama pull llama3.2-vision; cloud providers use the same API-key storage as the chat brain — the key stays on this machine.

◉ Run Describe Screen or a Guided Click to see the vision layer's report here

Bug Log
